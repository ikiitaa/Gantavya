# Gantavya - Travel Agency Web Application

Gantavya is a travel agency web application developed as a 5th semester BCA academic project. The platform allows users to explore travel packages, create accounts, make bookings, and complete payments through Khalti. It also includes an admin panel for managing travel packages and a chatbot for user assistance.

## Features

### User
- User registration and login
- Browse and view travel packages
- Book travel packages
- Make payments through Khalti
- Chatbot for assistance

### Admin
- Admin login
- Add travel packages
- View travel packages
- Update travel packages
- Delete travel packages
- Manage package information
